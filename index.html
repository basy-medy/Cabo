Cabo Score Tracker

Game Rules Summary

  • Goal: Have the lowest score when someone exceeds 100 points
  • Each round: Winner gets 0 points, others get their hand value
  • Calling Cabo: If you call Cabo but don't win → +5 penalty points
  • Kamikaze: End with two 12s + both 13s → You get 0, everyone else gets 50
  • Exactly 100: Score drops to 50
  • Game ends when any player exceeds 100 points

Card Values

Number Cards (0-6): Face value
Peek (7-8): 7-8 points
Spy (9-10): 9-10 points
Swap (11-12): 11-12 points
Cabo (13): 13 points
